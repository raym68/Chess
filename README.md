# Шахматы с дополнительными фигурами

- **Авторы:** Демченко Роман Александрович и Шакиров Александр Сергеевич
- **Группа:** ПИ25-2
- **Дисциплина:** Практикум по программированию

## Описание проекта

Приложение позволяет двум игрокам сыграть в шахматы за одним компьютером. Перед началом партии можно настроить стартовую расстановку: заменить ладей, коней и слонов на обычные или дополнительные фигуры. Выбранные фигуры располагаются одинаково у белых и чёрных. Доска, выбор фигур и протокол партии открываются в окне Tkinter.

## Функциональные возможности

- Ходы по очереди с подсветкой разрешённых клеток.
- Проверка шаха, мата и пата; подсветка короля под шахом.
- Рокировка, взятие на проходе и выбор фигуры при превращении пешки.
- Выбор стартовых фигур для линий `a`, `b`, `c`, `f`, `g` и `h`.
- Три дополнительные фигуры: грифон, верблюд и прыгающий слон.
- Выбор цвета доски и координаты по её периметру.
- Протокол партии с записью ходов.

## Требования к системе

- Python 3.9 или выше.
- Модуль tkinter и графическая среда. Команда `python3 -m tkinter` открывает тестовое окно.
- Windows, macOS или Linux.

Сторонние библиотеки, включая `pygame`, не требуются.

## Установка и запуск

### 1. Получение проекта

```bash
git clone https://github.com/raym68/Chess.git
cd Chess
```

Если проект уже находится на компьютере, откройте его папку в терминале.

### 2. Запуск игры

```bash
python3 run.py
```

В Windows команда может называться `python run.py` или `py run.py`. Откроется окно с классической начальной позицией.

## Управление

| Действие | Результат |
| --- | --- |
| Нажать свою фигуру | Показать разрешённые ходы |
| Нажать подсвеченную клетку | Сделать ход |
| Открыть «Новая партия…», выбрать фигуры и нажать «Начать партию» | Начать новую партию с выбранной расстановкой |
| Выбрать цвет доски | Сразу изменить оформление поля |
| Выбрать фигуру в окне превращения | Завершить превращение пешки |

## Структура проекта

- `run.py` — запуск приложения.
- `chess_ui.py` — окно Tkinter, доска, настройки и протокол партии.
- `backend/game.py` — правила, состояние партии и запись ходов.
- `backend/models.py` — модели доски и фигур.

## Пример использования

1. Запустите игру и нажмите «Новая партия…».
2. В меню выберите, например, грифона вместо ладьи на линии `a` и верблюда вместо коня на линии `b`.
3. Нажмите «Начать партию». Одинаковая расстановка появится у обеих сторон.
4. Выберите белую фигуру и нажмите одну из подсвеченных клеток. Запись хода появится в протоколе.

## Правила дополнительных фигур

- **Грифон (G)** ходит как слон или конь.
- **Верблюд (C)** прыгает на три клетки в одном направлении и на одну в перпендикулярном: `(3, 1)` или `(1, 3)`.
- **Прыгающий слон (E)** перепрыгивает на две клетки в любом из восьми направлений.

Ферзь и король в стартовой расстановке остаются на своих местах. Рокировка доступна только при выполнении её обычных условий, в том числе когда нужная ладья не была заменена.

## Ограничения

Партия хранится в памяти приложения до закрытия окна или начала новой игры. Игра рассчитана на двух людей за одним компьютером. Не реализованы ничья по повторению позиции, правилу 50 ходов и недостатку материала.
