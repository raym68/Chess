# Шахматы с дополнительными фигурами

- **Автор:** Демченко Роман Александрович

- **Дисциплина:** Практикум по программированию

## Описание проекта

Приложение позволяет двум игрокам сыграть в шахматы за одним компьютером. Перед началом партии можно настроить стартовую расстановку: заменить ладей, коней и слонов на обычные или дополнительные фигуры. Выбранные фигуры располагаются одинаково у белых и чёрных. Игровое поле открывается в браузере, а правила ходов обрабатывает Python-сервер.

## Функциональные возможности

- Ходы по очереди с подсветкой разрешённых клеток.
- Проверка шаха, мата и пата; подсветка короля под шахом.
- Рокировка, взятие на проходе и выбор фигуры при превращении пешки.
- Выбор стартовых фигур для линий `a`, `b`, `c`, `f`, `g` и `h`.
- Три дополнительные фигуры: грифон, верблюд и прыгающий слон.
- Выбор цвета доски и координаты по её периметру.
- Протокол партии с записью ходов.

## Требования к системе

- Python 3.9 или выше.
- Современный браузер.
- Windows, macOS или Linux.

Сторонние библиотеки, включая `pygame`, не требуются.

## Установка и запуск

### 1. Получение проекта

```bash
git clone https://github.com/raym68/Chess.git
cd Chess
```

Если проект уже находится на компьютере, откройте его папку в терминале.

### 2. Запуск сервера

```bash
python3 run.py
```

В Windows команда может называться `python run.py` или `py run.py`. После запуска откройте в браузере <http://127.0.0.1:8765>. Остановить сервер можно сочетанием `Ctrl+C` в терминале.

## Управление

| Действие | Результат |
| --- | --- |
| Нажать свою фигуру | Показать разрешённые ходы |
| Нажать подсвеченную клетку | Сделать ход |
| Выбрать фигуры в меню и нажать «Начать заново» | Начать новую партию с выбранной расстановкой |
| Выбрать цвет доски | Сразу изменить оформление поля |
| Выбрать фигуру в окне превращения | Завершить превращение пешки |

**Назначение файлов:**

- `run.py` — точка входа.
- `backend/models.py` — модель фигуры, создание доски и доступные виды фигур.
- `backend/game.py` — состояние партии, правила ходов и запись протокола.
- `backend/server.py` — HTTP-сервер и адреса API для связи с браузером.
- `frontend/index.html` — элементы страницы.
- `frontend/style.css` — оформление доски и меню.
- `frontend/app.js` — обработка нажатий и обновление страницы по ответу сервера.
- `frontend/icons/` — значки дополнительных фигур.

Такое разделение позволяет менять правила в бэкенде независимо от оформления страницы.

## Пример использования

1. Запустите сервер и откройте страницу игры.
2. В меню выберите, например, грифона вместо ладьи на линии `a` и верблюда вместо коня на линии `b`.
3. Нажмите «Начать заново». Одинаковая расстановка появится у обеих сторон.
4. Выберите белую фигуру и нажмите одну из подсвеченных клеток. Запись хода появится в протоколе.

## Правила дополнительных фигур

- **Грифон (G)** ходит как слон или конь.
- **Верблюд (C)** прыгает на три клетки в одном направлении и на одну в перпендикулярном: `(3, 1)` или `(1, 3)`.
- **Прыгающий слон (E)** перепрыгивает на две клетки в любом из восьми направлений.

Ферзь и король в стартовой расстановке остаются на своих местах. Рокировка доступна только при выполнении её обычных условий, в том числе когда нужная ладья не была заменена.

## Ограничения

Партия хранится в памяти сервера и сбрасывается после его перезапуска. Игра рассчитана на двух людей за одним компьютером. Не реализованы ничья по повторению позиции, правилу 50 ходов и недостатку материала.
