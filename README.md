# Шахматы

В игре есть стандартные фигуры и три дополнительные: грифон (G), верблюд (C), прыгающий слон (E).

## Запуск

Нужен Python 3.9+ и обычный браузер. Pygame и установка пакетов не нужны.

Из папки проекта запустите:

```bash
python3 run.py
```

Откройте <http://127.0.0.1:8765>. Остановить сервер: Ctrl+C. Если порт 8765 занят, поменяйте его в `backend/server.py`.

Игра для двух людей за одним компьютером. Реализованы обычные ходы, шах, мат, пат, рокировка, взятие на проходе и выбор превращения пешки. Не реализованы ничья по повторению позиции, правилу 50 ходов и нехватке материала. Настройки фигур меняют два места слонов одинаково у обеих сторон; цвет доски меняется сразу и сохраняется в браузере.
